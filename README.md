# 胡志辉 / Hu Zhihui

写代码，也写一点东西。

2016 年入行，长年在容错率极低的金融与医疗系统里摸爬滚打。这些严苛的业务教会我最深的一课：系统永远要对现实世界的混乱留有余地。国企的规矩沉淀了防御性思维，创业公司的快又剥掉了所有技术虚荣。

如今我更享受贯穿全栈，把 AI 与现代工具揉进具体业务。好的工程从不靠时髦名词装点，而是在成本、鲁棒性与体验之间，交出一套自洽且耐造的解法。
