# 胡志辉 / Hu Zhihui

写代码，也写一点东西。

从 2016 年入行起，大部分时间都在金融和医疗系统里打磨。这两个领域教给我最深的一件事，就是系统永远要对真实世界的混乱留有余地——无论是经不起半分差错的账目，还是关乎责任的业务留痕。国企的慢与规矩让我学会防御性思考，创业公司的快又逼着我切掉所有技术虚荣。

现在我更享受一个人贯穿全栈，把 AI 和现代工具揉进具体的业务里。对我来说，好的工程从来不是堆砌时髦名词，而是看透需求背后的本质，在成本、鲁棒性与体验之间，做出一套自洽且耐造的解法。
